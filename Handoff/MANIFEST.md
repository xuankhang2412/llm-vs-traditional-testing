# HANDOFF PACKAGE MANIFEST

**Benchmark Package:** SWT301 Black-Box Test Generation Benchmark
**Timestamp:** 2026-11-05

This manifest details the directory structure, file inventory, and descriptions for all assets included in the research handoff package.

## Directory Overview

| Directory / Path | Description |
| :--- | :--- |
| `Reference/` | Authoritative literature reference PDF (`Benchmarking-Software-Test-Cases-Produced-by-Gener.pdf`) |
| `Spec/` | Clean specifications (v1.1.1), `csv_format.md`, and prompt templates in `llm_prompts/` |
| `Projects_READMEs/` | Functional specifications and seeded defect catalogues for Projects 1 through 4 |
| `Suites/` | All 34 normalized test suites across 4 apps (TFD, PICT_plain, PICT_constrained, LLM C1-C6) |
| `Suites/_raw_llm/` | Byte-for-byte unedited original copies of LLM suites that underwent format normalization |
| `LLM_ready/` | 24 pre-assembled ready-to-paste prompt text files for all apps and conditions |
| `Logs/` | `generation_log.csv` (LLM measured minutes) and `TFD_tester_notes.txt` (TFD self-reported notes) |
| `Audit/` | Comprehensive inventory, validation logs, normalization logs, and audit reports |
| `Results/` | Matrix long CSVs for all 34 suites, 8 summary CSV metrics, 5 PNG charts, scripts, and `summary.md` |
| `KNOWN_ISSUES.md` | Authoritative notes on normalizations, quotas, rounding rules, and TFD provenance |
| `MANIFEST.md` | Complete file inventory and metadata catalog (this file) |
